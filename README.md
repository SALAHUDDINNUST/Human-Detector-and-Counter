A real-time human detection and counting system using computer vision. This project implements multiple approaches to detect and count people in images, video streams, and webcam feeds.

## ✨ Features

- 🎥 **Real-time detection** from webcam
- 📁 **Video file processing** with statistics
- 📊 **Live counting** with maximum and average tracking
- 🖼️ **Multiple detection methods** (HOG, YOLO optional)
- 💾 **Screenshot capture** functionality
- 📈 **Statistics display** (FPS, counts, timestamps)
- 🎨 **Clean GUI interface** (Tkinter version)
- 🌐 **Web interface** (Flask version)
- 📝 **Entry/Exit tracking** (advanced version)

## 🛠️ Technologies Used

- **Python 3.8+** - Core programming language
- **OpenCV** - Computer vision and image processing
- **NumPy** - Numerical operations
- **Tkinter** - GUI interface (optional)
- **Flask** - Web interface (optional)
- **HOG Descriptor** - Human detection algorithm

## 📋 Prerequisites

Before you begin, ensure you have:
- Python 3.8 or higher installed
- Webcam (for real-time detection)
- Basic understanding of Python
- 4GB RAM minimum (8GB recommended)
